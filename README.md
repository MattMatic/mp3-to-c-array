# PCM Scope

A client-side web app that converts MP3 or WAV files into `int16_t` C
arrays — ready to paste straight into firmware. Drag and drop one or more
files, choose an output sample rate, mono/stereo encoding, and optional
silence trimming, and download a self-contained `.h` file per track.

Everything runs in the browser. Files are decoded and resampled locally
with the Web Audio API — nothing is uploaded anywhere.

```c
const int16_t my_song_table[] =
{
    0x0000, 0x0324, 0x0648, 0x096A, 0x0C8C, 0x0FAB, 0x12C8, 0x15E2, ...
};

const uint32_t my_song_table_len = 24000u;
```

## Features

- **Drag and drop** multiple MP3 or WAV files at once (or click to browse)
- **Configurable output format**: sample rate (8 kHz–48 kHz) and
  mono / stereo (stereo output is interleaved `L,R,L,R,...`)
- **Silence trimming**: optionally strip leading/trailing silence below a
  configurable threshold (-40/-50/-60 dBFS), with a small padding margin
  left in place to avoid clicks
- Correct resampling and channel mixing via `OfflineAudioContext`
  (standard down-mix for stereo → mono, duplication for mono → stereo)
- Live waveform preview and a scrollable hex preview of the generated array
- Download the generated `.h` file, or copy the array straight to the
  clipboard
- No build step, no dependencies, no server — plain ES modules

## Getting started

Because the app uses native ES modules (`<script type="module">` and
`import`/`export`), it must be served over `http://` rather than opened
directly as a `file://` URL. From the project root:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Any static file server works equally well (`npx serve`, VS Code's Live
Server extension, etc.).

## Usage

1. Open the app in a browser (Chrome, Firefox, Safari, or Edge — anything
   with Web Audio API support).
2. Set the desired **sample rate**, **channels**, and **trim silence**
   threshold in the output format panel. These apply to files added from
   that point onward.
3. Drag one or more `.mp3` or `.wav` files onto the drop zone, or click
   **choose files…**.
4. Each file is decoded and converted automatically. When it finishes,
   use **download .h** to save the generated header, **copy array** to
   copy it to the clipboard, or **preview** to inspect the hex dump
   in-page.

## Output format

Each generated header is self-contained and dependency-free:

```c
/*
 * Generated by PCM Scope from "my_song.mp3"
 * Source:  44100 Hz, stereo, 3.214s
 * Encoded: 24000 Hz, mono, signed 16-bit PCM
 * Samples: 77136
 */

#ifndef MY_SONG_H
#define MY_SONG_H

#include <stdint.h>

const int16_t my_song_table[] =
{
    0x0000, 0x0324, 0x0648, 0x096A, ...
};

const uint32_t my_song_table_len = 77136u;

#endif /* MY_SONG_H */
```

- Values are formatted as uppercase `0x%04X` hex literals, 16 per line,
  matching common embedded wave-table conventions.
- Negative samples use their two's-complement 16-bit representation
  (e.g. `-32767` prints as `0x8001`).
- For stereo output, samples are interleaved per frame (`L,R,L,R,...`);
  the header comment reports both the total value count and the frame
  count.
- The array/guard names are derived from the source filename, sanitized
  into a valid C identifier (e.g. `My Song #1.mp3` → `My_Song_1`).

## Project structure

```
mp3-to-c-array/
├── index.html                 Page shell, drop zone, settings panel, strip template
├── css/
│   └── style.css              Styling
└── js/
    ├── main.mjs                Entry point — wires everything together
    ├── audioDecoder.mjs        MP3/WAV decode + resample/downmix via Web Audio API
    ├── pcmConverter.mjs        Float32 PCM → int16 PCM (mono + interleaved)
    ├── cArrayFormatter.mjs     int16 samples → formatted C header source
    ├── waveformRenderer.mjs    Canvas oscilloscope-style waveform trace
    ├── silenceTrimmer.mjs      Leading/trailing silence trimming
    ├── dragDropZone.mjs        Drag-and-drop / file-picker wiring
    ├── fileStrip.mjs           Per-file UI: orchestrates decode → convert → render
    └── downloadUtils.mjs       File download + clipboard helpers
```

Each module has a single responsibility and no build step is required —
open `index.html` (via a local server) and it runs as-is.

## Browser support

Requires `AudioContext`, `OfflineAudioContext`, and ES modules — supported
in current Chrome, Firefox, Safari, and Edge. The app checks for these
APIs on load and shows a warning if they're unavailable.
